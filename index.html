    Como funciona?
    • Se o nome da cidade já existir, os dados dela são substituídos pela nova tabela; se não existir, a cidade é adicionada.
    • Colunas usadas: latitude, longitude, price, neighbourhood, room_type e, quando existirem, avaliações, noites mínimas, disponibilidade e anfitrião.
    • O arquivo de bairros (neighbourhoods.geojson do Inside Airbnb) deixa o mapa coroplético com o desenho real dos bairros.
    • Os dados ficam guardados apenas neste navegador. Quando o dashboard estiver publicado (ex.: Vercel) junto com a pasta Dados e o arquivo Dados/cidades.json, as cidades carregam sozinhas.
